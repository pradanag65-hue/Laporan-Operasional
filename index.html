Import Data

Upload data operasional bulanan dalam format CSV

Import CSV Bulanan

Satu file = satu bulan, berisi baris untuk tiap trayek. Semua data tersimpan ke Google Sheet dan langsung muncul di grafik.
1
Download template
Template CSV sudah berisi 20 baris trayek (1A–15, Listrik) sesuai urutan standar.
2
Isi di Excel/Sheets
Isi kolom Penumpang, Ritase, Headway, Kecepatan, RTT, KmTempuh, LoadFactor. Kolom kosong boleh dibiarkan.
3
Upload lagi ke sini
Simpan sebagai .csv, upload, cek pratinjau, lalu klik Simpan Semua.
Mendukung file .xlsx, .xls, dan .csv — formatnya sama, tinggal pilih yang paling nyaman kamu isi.

Pratinjau Data

Input Manual (satu trayek/bulan)

Untuk koreksi cepat tanpa perlu upload file.
Load Factor boleh diisi desimal (0.52) atau angka persen langsung (52 / 52,3) — otomatis terdeteksi. Headway & RTT boleh diisi menit langsung (124) atau notasi jam.menit (2.09 = 2 jam 9 menit) — otomatis dikonversi ke menit.
